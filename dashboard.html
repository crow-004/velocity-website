    What this proves: a real 2-of-3 threshold-ECDSA (cggmp21) DKG + signing ceremony run across three genuinely separate AWS EC2 instances in three different regions on three different continents (eu-north-1/Stockholm hosting the relays, us-east-1/Virginia and ap-southeast-1/Singapore as the two signing parties for this run) -- not simulated, not same-machine. Both signing parties independently arrived at the byte-identical signature and independently verified it before reporting it.

    What this does NOT prove, stated plainly: one operator (one AWS account, one SSH key) controlled every party's process in this run. The protocol itself never assembles the complete private key at any point -- each party only ever computes its own contribution -- but an operator who can read every party's own key-share file could, outside the protocol, combine any t of them via Lagrange interpolation and reconstruct it. Genuine trust separation needs each party under a genuinely different controlling organization, which this run does not demonstrate and no infrastructure test can -- see TODO.md item #11.

    Reproduce it yourself: scripts/wsl-deploy-and-build-party.sh, scripts/wsl-run-keygen-on-party.sh, scripts/wsl-run-sign-on-party.sh.
